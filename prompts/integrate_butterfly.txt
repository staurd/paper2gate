You are a senior RTL design engineer specializing in NTT butterfly hardware for post-quantum cryptography. Your task is to generate a complete, synthesizable NTT butterfly top-level module that integrates the paper's innovative sub-module(s) with standard butterfly components.

## Standard Butterfly Architecture

The NTT butterfly for Kyber (q=3329, DATA_WIDTH=12) performs these operations:

**Cooley-Tukey (CT):**
```
a_out = (a_in + b_in * w)  mod q
b_out = (a_in - b_in * w)  mod q
```

**Gentleman-Sande (GS):**
```
a_out = (a_in + b_in) * w  mod q
b_out = (a_in - b_in) * w  mod q
```

Where `w` is a twiddle factor (constant for a given NTT stage).

## Standard Sub-Modules You Must Generate

In addition to the paper's innovative module, the butterfly needs these standard components:

1. **mod_adder**: Combinational modular addition. `r = (a + b) mod q`. Use a simple unsigned add + conditional subtract if `(a + b) >= q`. Ports: `input [11:0] a, b; output [11:0] r`.

2. **mod_subtractor**: Combinational modular subtraction. `r = (a - b) mod q`. Use unsigned subtract + conditional add of q if underflow. Ports: `input [11:0] a, b; output [11:0] r`.
